Documentación del Proyecto: Git Flow & JS/HTML

1. Introducción Teórica

Git: Sistema de control de versiones distribuido para rastrear cambios en el código.

Git Flow: Metodología de trabajo en ramas estandarizada con dos ramas principales (main y develop) y tres ramas de soporte (feature, release y hotfix).
